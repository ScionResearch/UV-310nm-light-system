RTC setup:

sudo i2cdetect -y 1
Check that the RTC is present on I2C bus (address 68 for DS1307 module)

Edit the boot file:
sudo nano /boot/firmware/config.txt

Add line to end of file:
dtoverlay=i2c-rtc,ds1307

Save and reboot

Disable fake HW clock:
sudo apt-get -y remove fake-hwclock
sudo update-rc.d -f fake-hwclock remove
sudo systemctl disable fake-hwclock

Edit HW clock script:
sudo nano /lib/udev/hwclock-set

comment out # these lines:
#if [ -e /run/systemd/system ] ; then
#    exit 0
#fi

#/sbin/hwclock --rtc=$dev --systz

Sync time from Pi to RTC:
sudo hwclock -r

Check date:
date

Source - https://learn.adafruit.com/adding-a-real-time-clock-to-raspberry-pi/set-rtc-time

Setup desktop to run chromium in kiosk mode:

Create autostart file in user home directory:
mkdir /home/admin/.config/lxsession
mkdir /home/admin/.config/lxsession/LXDE-pi
cp /etc/xdg/lxsession/LXDE-pi/autostart /home/admin/.config/lxsession/LXDE-pi/

Edit to add chromium to autostart:
nano /home/admin/.config/lxsession/LXDE-pi/autostart

Add line:
@chromium-browser --kiosk

Source - https://forums.raspberrypi.com/viewtopic.php?t=294014
